Stack Overflow has definitely declined as a reputation-building platform. Here are the main ways people build technical reputation now:

**Writing**

- Substack or a personal blog — long-form technical writing still carries a lot of weight
- Writing for established publications like ACM, IEEE, or industry blogs

**Building things in public**

- GitHub — a well-maintained repo with real users is probably the strongest signal today
- Contributing meaningfully to high-profile open source projects

**Video / Streaming**

- YouTube tutorials or deep-dives
- Twitch coding streams (niche but has a dedicated audience)

**Speaking**

- Conference talks (GDC, PyCon, Strange Loop, etc.) — still very effective, hard to fake
- Local meetups to start building toward bigger stages

**Social platforms**

- Twitter/X still works for technical audiences, especially for sharing ideas and research
- LinkedIn has gotten surprisingly serious for engineering content
- Bluesky is growing as an alternative

**Communities**

- Discord servers around specific technologies
- Hacker News — a well-received post or comment there still carries real signal

---

The approach that still works best is Erin Catto's: **build something genuinely useful and let it speak for itself.**
