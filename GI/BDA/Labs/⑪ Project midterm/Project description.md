# Final Project - Cherry Picking Exam

For the project exam, you must come up with your project idea. You can prepare the project at home, but you must build the actual project during the double lab session in180 minutes.

To ensure that all completed projects are comparable in terms of complexity, we have created a **price list** that assigns a point value to different implementation features. Since each project idea may require a different combination of features, we cannot prescribe exactly what your completed project must include. **Everyone is free to decide where to place the emphasis - that's why we call it Cherry Picking Exam.**

The task involves building an ASP.NET and Windows Forms application that provides a solution (or partial solution) to a real or fictional problem. (More on ASP.NET on the 10th week.)

- Seat reservation system of an office
- Simple order tracking system with customers, products, invoices, and invoice lines
- Apps to track sport events
- Santa's gift distribution system
- Simple ticketing system
- Virtually anything

## Rules

❶ You need to create the database at home. You need to fill up the database with some sample data to prove that your project works.  
- We suggest you create a SQL database in Azure.  
- But you can use SQLite as well. More on SQLite on the lecture!  
- If you get stuck with Azure we can create your personal database on `bit.uni-corvinus.hu`. Just write me on teams.
- You can use a Service Based database as well. 

❷ You may bring the `Scaffold-DbContext` command or, if you're using a local Service-Based Database, the SQL script that creates the database.

❸ The .NET **project should be prepared at home** unless you are an experienced .NET developer 🙂. You can check the point values of the included features according to the **"Pricing Table"** below.

❹ The C# project must be built during the **2x90-minute** sessions of the labs. **We will not have a break between the timeslots.**

❺ Get yourself a database:
- You can use create your own database . 
- You can use databases you created for other courses as well. 
- A custom database earns 7 points, but if we find identical databases submitted, neither will receive points. 
- You can use an arbitrary sample database created by someone else, but they earn you no points. 


❻ You can collect up to **30 points in total**, but only working features earn points — no partial credit is given. 

❼ The project should be unique — we don’t want to see identical solutions! Be creative 🙂!


We recommend you to start with planning! Draw your concept on a sheet and calculate the point values using the Pricing Table!

## Background

In previous years, C# courses ended with project submissions. We’ve found that real understanding develops when students design and build their own applications. However, in the context of a competitive scholarship, it’s difficult to assess how much outside help went into a project. This test approach helps evaluate individual effort more reliably. No matter how you gained knowledge, this approach measures what you can do in practice. I'm glad to help via Teams!
